## البدء مع Claude Code
1. أنشئ مستودعاً جديداً `daydan`، وضع هذا المجلد داخله باسم `handoff/`.
2. انسخ `handoff/CLAUDE.md` إلى جذر المستودع.
3. افتح Claude Code في المستودع وابدأ ببرومبت **0 · Kickoff** من `prompts/claude-code-prompts.md`، ثم مرحلة واحدة في كل جلسة.

## قرارات هذه الجلسة
- الشعار النصي: «اجعل القرآن دَيْدَنك».
- النطاق المجاني: `daydanquran.pages.dev`.
- النشر اليومي 07:00 بتوقيت مكة، والتذكير المسائي 20:00.
