# ٤. خط إنتاج المحتوى

## المصادر
| المحتوى | المصدر | ملاحظة |
|---|---|---|
| نص الآيات (للتحقق والبحث) | Tanzil (Uthmani) | شرط: نسخ حرفي، ذكر المصدر ورابط tanzil.net |
| توزيع الآيات على الصفحات | Quran.com API v4 (`verses/by_page`) أو QUL | مصحف المدينة 604 صفحة |
| صورة صفحة المصحف | النسخة الرقمية الرسمية لمجمع الملك فهد (dm.qurancomplex.gov.sa) | تُستخدم كما هي دون أي تعديل |
| التفسير الميسر | Quran.com API (tafsir بالاسم Muyassar) أو QUL | الترخيص يحتاج تأكيداً، انظر `07-licenses.md` |
| تلاوة الحصري مرتّلاً | ملفات آية آية (Quran.com CDN / everyayah) | الترخيص يحتاج تأكيداً، انظر `07-licenses.md` |

## الخطوات
1. **جلب:** لكل صفحة 1..604: الآيات (key, text_uthmani, surah, juz) + التفسير + روابط الصوت. الكود المرجعي: `reference-code/fetch-pages.mjs` (يحدد معرّف الحصري والميسر **بالاسم** من الـAPI ويتوقف إن لم يكن التطابق فريداً).
2. **تحقق آلي (يفشل البناء عند أي خطأ):**
   - مجموع الآيات = 6236، وكل آية في صفحة واحدة فقط، والصفحات متصلة بلا فجوات.
   - نص كل آية يطابق Tanzil حرفاً بحرف (بعد توحيد الترميز Unicode NFC).
   - لكل آية تفسير غير فارغ.
   - لكل آية ملف صوتي موجود، ومدته > 0.
3. **الصوت:** دمج آيات الصفحة بترتيبها في ملف واحد (ffmpeg concat، MP3 أحادي ~64kbps). البسملة: اتّباع ما في ملفات المصدر دون إضافة. حفظ المدة الفعلية لكل صفحة.
4. **الصور:** تعبئة القوالب في `templates-html/` (استبدال ما بين `[ ]`) ورسمها بـPlaywright بالمقاس الدقيق:
   - `Post` 1080×1080: صورة الصفحة + رقم الصفحة + السورة + الجزء.
   - `Tafsir` 1080×1080: بطاقة لكل آية أو مجموعة آيات؛ إن تجاوز النص المساحة يُقسَّم على بطاقات متتالية "١ / ٣". **التقسيم عند حد جملة، لا في منتصف كلمة.**
   - `Story` 1080×1920، `Reminder` 1080×1080، `ReelCover` 1080×1920.
   - الأرقام بالأرقام العربية المشرقية.
5. **الفيديو:** فيديو الصفحة كاملة لفيسبوك (صورة الصفحة + الصوت). ريلز إنستغرام: مقطع مختار ≤ 90 ثانية، 9:16.
6. **قياس:** عدد بطاقات التفسير لكل صفحة، وأطول منشور (حد إنستغرام للمنشور متعدد الصور يجب التحقق منه وقت البناء)، ومدد الصوت، وحجم كل الوسائط. تقرير `content/v1/report.json`.
7. **مراجعة بشرية:** صفحة إدارة تعرض كل صفحة بمخرجاتها مع زر "معتمد". لا تُنشر صفحة غير معتمدة. المراجعة الأولى على أول 30 صفحة قبل الإطلاق على الأقل.
8. **تجميد:** رفع `content/v1/<page>/...` إلى R2 مع `manifest.json` (hash لكل ملف). أي تعديل لاحق = إصدار جديد `v2`.
