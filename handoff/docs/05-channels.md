# ٥. القنوات

| القناة | ما يُنشر يومياً (07:00 مكة) | الأتمتة | التتبّع |
|---|---|---|---|
| **الموقع (PWA)** | صفحة اليوم: الصورة، التلاوة، التفسير، زر "قرأت"، الختمة | كامل | نعم |
| **تيليجرام** | ألبوم (الصفحة + بطاقات التفسير) ← ملف التلاوة ← النص الموحد + زر "قرأت ✅" | كامل (Bot API) | نعم، عبر البوت |
| **إنستغرام** | منشور متعدد الصور (الصفحة + بطاقات التفسير) + ستوري تذكير 20:00؛ ريل 3 مرات أسبوعياً | Content Publishing API | لا |
| **فيسبوك** | نفس المنشور متعدد الصور + فيديو الصفحة كاملة | Graph API | لا |

## تيليجرام
- القناة `@daydanquran` والبوت `@daydanquran_bot` (يُنشأ من @BotFather). الرمز في متغير بيئة فقط.
- البوت: `/start` (يربط الحساب إن جاء مع token)، زر "قرأت" يكتب في `reading_log`، أمر لضبط وقت التذكير، تذكير مسائي لمن لم يقرأ إن كانت قناته الأساسية تيليجرام.

## إنستغرام وفيسبوك (Meta)
- الحساب يجب أن يكون **Business** ومربوطاً بصفحة فيسبوك (شرط نشر الستوري عبر الـAPI).
- الريلز عبر الـAPI: 9:16، بين 5 و90 ثانية.
- حد النشر اليومي: **استعلم عن `content_publishing_limit` قبل النشر ولا تكتبه ثابتاً** (توثيق Meta نفسه متناقض بين 50 و100 منشور/24 ساعة).
- يحتاج تطبيق Meta Developer ومراجعة صلاحيات (instagram_content_publish، pages_manage_posts...). **قدّم الطلب مبكراً**، قد يستغرق أسابيع.
- الحالة الحالية: ربط إنستغرام بالصفحة متوقف بسبب تقييد مؤقت من Meta (انظر `09-open-questions.md`).

## واتساب
الـAPI الرسمي (Cloud API) لا يدعم القنوات إطلاقاً، والبدائل غير الرسمية تعرّض الرقم للحظر. القرار: لوحة الإدارة تجهّز نص وصورة اليوم بزر نسخ، والنشر يستغرق دقيقة يدوياً.
