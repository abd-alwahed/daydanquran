# حزمة هوية دَيْدَن

**svg/** ملفات متجهية بلا خطوط (الاسم محوّل إلى أشكال)، تعمل في أي مكان:
- `daydan-logo-horizontal*.svg` التوقيع الأفقي: ملوّن، أبيض للخلفيات الداكنة، لون واحد.
- `daydan-logo-vertical.svg` التوقيع العمودي.
- `daydan-mark*.svg` الرمز وحده. `daydan-icon.svg` أيقونة التطبيق. `daydan-favicon.svg` الرمز المختصر للأحجام الصغيرة.
- `daydan-avatar.svg` صورة الحساب.

**png/**
- `daydan-avatar-1080.png` صورة الحساب لتيليجرام وإنستغرام وفيسبوك.
- `daydan-icon-1024/512/192/180.png` أيقونات التطبيق والموقع (180 لأجهزة آبل).
- `daydan-favicon-48/32/16.png` أيقونة المتصفح وإضافة كروم.
- `daydan-logo-*-2000.png` التوقيعات بدقة عالية.

**tokens.css / tokens.json** الألوان والخطوط والمقاسات جاهزة للكود، مع الوضع الليلي.

قواعد سريعة: الذهبي لورد اليوم فقط · لا يوضع الشعار على صفحة المصحف · الاسم مشكول دائماً · تحت 32 بكسل يُستخدم الرمز المختصر.
الخطوط من Google Fonts برخصة OFL المفتوحة: El Messiri · Scheherazade New · Tajawal.
