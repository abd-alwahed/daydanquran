# برومبتات كتابة المحتوى التسويقي

**طريقة الاستخدام:** ابدأ أي محادثة مع Claude بلصق "سياق دَيْدَن" أدناه مرة واحدة، ثم استخدم البرومبت المناسب. استبدل ما بين { } بمحتواك.

> قاعدة لا استثناء فيها: لا تطلب من الذكاء الاصطناعي كتابة آية أو حديث أو تفسير من الذاكرة. انسخ النص بنفسك من مصدر موثق والصقه، واطلب منه الصياغة حوله فقط.

---

## سياق دَيْدَن (الصقه أولاً)
```
أنت تكتب لمشروع "دَيْدَن": مشروع دعوي غير ربحي ومجاني ينشر كل يوم صفحة واحدة من القرآن مع التفسير الميسر وتلاوة الحصري، على الموقع وتيليجرام وإنستغرام وفيسبوك وواتساب. الجميع يقرأ الصفحة نفسها في اليوم نفسه. الشعار: «اجعل القرآن دَيْدَنك». الدَّيْدَن = العادة الدائمة. المعرّف: daydanquran.
نبرة الكلام: فصحى سهلة، دافئة بلا تكلّف، ترغّب ولا تلوم، قصيرة (جملة أو جملتان)، وقورة: بلا مبالغات ولا علامات تعجب متكررة ولا رموز تعبيرية.
ممنوع: "اكتب آمين"، "شارك لتنال الأجر"، أي لوم أو تخويف أو أرقام عن الصفحات الفائتة، الإعلان عن إنجاز شخصي، كتابة آيات أو أحاديث من الذاكرة.
الوسوم الثابتة فقط: #دَيدَن #ورد_اليوم #القرآن_الكريم
اكتب الاسم دائماً مشكولاً: دَيْدَن. والأرقام بالأرقام العربية (١٢٣).
```

## ١. منشورات حملة الإطلاق
```
اكتب 7 منشورات لأسبوع ما قبل إطلاق دَيْدَن، منشور لكل يوم، بهذه المواضيع بالترتيب:
1) معنى الاسم «اجعل القرآن دَيْدَنك» 2) الفكرة: صفحة واحدة كل يوم 3) كيف تعمل: الصفحة والتفسير والتلاوة 4) أين تجدنا 5) الختمة 604 أيام والجميع على الصفحة نفسها 6) دعوة: ادعُ من تحب ليقرأ معك 7) غداً نبدأ.
لكل منشور أعطني: نصاً قصيراً للتصميم (عنوان ≤ 6 كلمات + سطر توضيحي ≤ 12 كلمة) يناسب قالب "إعلان"، ونص المنشور (caption) ≤ 60 كلمة، ونص ستوري ≤ 8 كلمات.
موعد الإطلاق: {التاريخ}.
```

## ٢. منشور متعدد الصور تعليمي
```
حوّل هذا الموضوع إلى منشور متعدد الصور من {5} شرائح لقوالب دَيْدَن: الموضوع: {مثلاً: كيف تبني عادة القراءة اليومية}.
الشريحة الأولى غلاف: عنوان ≤ 6 كلمات + وصف ≤ 10 كلمات. كل شريحة وسطى: عنوان ≤ 5 كلمات + شرح ≤ 30 كلمة. الأخيرة خاتمة «اجعل القرآن دَيْدَنك» مع دعوة واحدة.
ثم نص المنشور ≤ 50 كلمة.
لا تستخدم أي آية أو حديث إلا هذا النص الذي أعطيك إياه حرفياً مع مصدره: {النص والمصدر أو اكتب: لا يوجد}.
```

## ٣. منشور الجمعة
```
اكتب منشور جمعة لدَيْدَن: "جمعة مباركة" + تذكير لطيف بسورة الكهف + خلاصة الأسبوع: قرأنا هذا الأسبوع الصفحات من {٢٤٥} إلى {٢٥١} من سورة {اسم}.
أعطني: سطر التصميم ≤ 10 كلمات، ونص المنشور ≤ 40 كلمة.
```

## ٤. منشور إتمام جزء
```
اكتب منشور احتفال هادئ لإتمام الجزء {١٣} معاً في دَيْدَن. بلا مبالغة، بلا "مبروك!!!"، بل حمد وتشجيع على الاستمرار ودعوة من فاته شيء لقائمة "اقضِ ما فاتك" بلا لوم.
أعطني: سطر التصميم ≤ 8 كلمات، ونص المنشور ≤ 40 كلمة، ونص ستوري ≤ 8 كلمات.
```

## ٥. منشورات المواسم
```
اكتب {3} منشورات لموسم {رمضان / العشر من ذي الحجة} لدَيْدَن، تربط الموسم بالاستمرار على صفحة اليوم، لا بزيادة الكمية فجأة. لكل منشور: اسم الموسم، رسالة ≤ 7 كلمات للتصميم، جملة ربط ≤ 15 كلمة، ونص منشور ≤ 50 كلمة.
```

## ٦. رسالة "استمر بعد رمضان"
```
اكتب 3 صيغ لرسالة تُنشر بعد عيد الفطر تشجع من بدأ مع دَيْدَن في رمضان على الاستمرار. الفكرة: رمضان بداية العادة لا نهايتها، وصفحة واحدة تكفي. كل صيغة ≤ 30 كلمة، بلا لوم.
```

## ٧. رسالة طلب شراكة
```
اكتب رسالة قصيرة (≤ 90 كلمة) أرسلها إلى {مسؤول حلقة تحفيظ / مدير صفحة دعوية / مجموعة طلابية}، أعرّف فيها بدَيْدَن (غير ربحي، مجاني، صفحة يومية مع التفسير والتلاوة) وأطلب طلباً واحداً واضحاً: {نشر منشور الإطلاق / تثبيت رابط القناة أسبوعاً / اعتماده ورداً يومياً للطلاب}. نبرة محترمة وغير ملحّة. أعطني صيغتين: رسمية وودية.
```

## ٨. نبذة الحسابات
```
اكتب نبذة لحساب دَيْدَن على {إنستغرام (≤ 150 حرفاً) / تيليجرام / فيسبوك}. يجب أن تشرح معنى الاسم، وما ينشر يومياً، ووقت النشر 7 صباحاً بتوقيت مكة، ورابط daydanquran.pages.dev. أعطني 3 صيغ.
```

## ٩. ردود جاهزة على التعليقات
```
اكتب ردوداً قصيرة (≤ 25 كلمة) ودودة لهذه المواقف في تعليقات دَيْدَن:
1) "كيف أبدأ؟" 2) "فاتتني أيام" 3) "لماذا هذا التفسير بالذات؟" 4) "هل هناك تطبيق؟" 5) "جزاكم الله خيراً" 6) سؤال فقهي خارج نطاق المشروع (أحِله بلطف إلى أهل العلم) 7) تعليق جدلي (لا ترد؛ اكتب فقط: يُخفى).
```

## ١٠. نص فيديو تعريفي قصير
```
اكتب نص فيديو تعريفي لدَيْدَن مدته 30 ثانية (≈ 70 كلمة) بصوت هادئ، يُعرض فوقه شعار دَيْدَن وصفحات المصحف وواجهة الموقع (بلا وجوه ولا موسيقى). البنية: سؤال افتتاحي، الفكرة، كيف تعمل، الدعوة «اجعل القرآن دَيْدَنك». ضع لكل جملة اقتراحاً لما يظهر على الشاشة.
```
